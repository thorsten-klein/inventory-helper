Touch Drag Test for Reorder Screen

Manual Test Instructions:

  1. Open the inventory helper app on a touch device (or use Chrome DevTools device mode)
  2. Upload an XLSX file and navigate to the editor screen
  3. Try the following tests:

Test Cases

Test 1: Touch drag from drag handle

Steps:

  1. Touch and hold the drag handle (⋮⋮ icon) on the left of an item card
  2. While holding, drag your finger to another item's position
  3. Release your finger

Expected: Item should move to the new position

Test 2: Visual feedback during drag

Steps:

  1. Touch and hold the drag handle on an item
  2. While dragging, observe the visual feedback

Expected:

  • Dragged item should have a visual indication (dragging class)
  • Target drop position should show a line indicator (drag-over-top or drag-over-bottom)

Test 3: Swipe gestures still work

Steps:

  1. Swipe right on an item (not starting from drag handle)
  2. Swipe left on an item (not starting from drag handle)

Expected:

  • Swipe right should lock/unlock the item
  • Swipe left should prompt to delete the item

Steps:

  1. Lock an item by swiping right
